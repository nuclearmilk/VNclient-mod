##  Mod 版新增功能 / 修复
在原版的基础上，本修改版进行了以下体验优化：
- **列表显示优化**：增加列表和详情页可选优先显示中文标题选项。
- **标题复制优化**：在详情页长按，可**分别**单独复制中文大标题和日文原名小标题。
- **制作商搜索修复**：修复了原版“点击查看该制作方的作品”会导致白屏及 400 报错的问题，现在底层通过制作商 ID 精准匹配该厂商的所有作品。
- **界面清爽化**：跳转到搜索页面时，默认折叠占用屏幕巨大的“高级筛选”面板，把空间留给游戏列表。
- **交互优化**：取消了列表向左侧滑动删除游戏的功能，防误触。修复了标签编辑界面无法取消选中标签的 Bug。

# VNclient-mod-1.3.6 更新总结

## 功能更新

- 作品角色区域移除声优显示，避免作品页角色卡片信息过多。
- 角色详情页只查询并显示当前角色对应的声优。
- 声优标签改为与角色特质一致的浅绿色标签风格，并支持点击进入声优详情。
- 声优详情页增加配音角色列表，点击角色可进入角色详情。
- 声优详情页的参演作品、歌曲分组和配音角色支持名称优先级：中文 → 日文 → 其他语言；角色没有中文时优先日文。
- `songs` 分组名称改为“歌曲”。
- 作品标题显示优先级调整为：中文 → 日文 → 其他语言。
- 作品详情页顶部信息、标签栏和标签内容合并为统一滚动区域，支持从任意区域连续上下滑动。
